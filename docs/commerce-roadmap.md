# Commerce Roadmap

Aligned with [implementation-roadmap.md](implementation-roadmap.md).

| Phase | Commerce-related work |
|-------|----------------------|
| **1** | Unified customers; no storefront |
| **2** | Stock locations, movements, reservations **table** designed/migrated even if unused by UI |
| **3** | Product catalog + POS channel sales on canonical IDs |
| **4** | Stability; inventory reservation APIs tested |
| **5** | Public catalog, accounts, cart, checkout, online payment, branch pickup (BOCP) |
| **6** | Delivery, returns, promotions, reviews, customer mobile app |
| **7** | Multi-vendor marketplace only if commercially justified |

## Phase 5 exit criteria

- Online order cannot oversell against POS
- Same payment confirmation path as repairs/POS
- Branch pickup code verification in ops/Android
- Customer can see order + repair history in one account

## Non-goals until Phase 5+

Storefront marketing CMS, complex promotions engine, marketplace settlements.
