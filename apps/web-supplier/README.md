# TechLane supplier portal

Web portal for suppliers to quote part requests, issue collection QR codes, and track credit.

```bash
cd apps/web-supplier
npm install
npm run dev
```

Dev server: `http://localhost:5176`  
API default: `http://localhost:8080/api/v1` (override with `VITE_API_BASE`)

## Demo
- Seeded login: `supplier@techlane.local` / `password`
- Or accept an invite token from web-ops → Suppliers
